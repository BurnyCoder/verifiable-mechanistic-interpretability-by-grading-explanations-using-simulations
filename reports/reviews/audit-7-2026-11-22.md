# Seventh independent audit — 2026-11-22

*Made without reading the earlier reviews or audit scripts, after every round-2 number had been seen. No new agent
runs, no API spend. Results are at N = 3 — not yet N = 10. Preregistration deviation 14 records the changes.*

## 1. Scope and method

1. **Hypothesis verdicts.** Every round-2 verdict was re-derived from the raw run records by
   `scripts/audit7/verdicts.py`, which imports neither the project's code nor scipy (numpy and the standard library
   only). Every null distribution is enumerated in full: Jonckheere–Terpstra over all 369,600 (H1) or 1,680
   (replications) assignments of runs to levels, Mann–Whitney over all splits, Wilcoxon over all 2⁶ sign patterns, and
   the bootstrap over all nⁿ resamples per group. For H1's Spearman criterion the script takes the minimum ρ over all
   27⁴ = 531,441 within-level resamples, which bounds the bootstrap interval's lower end.
2. **Scores.** `scripts/audit7/regrade.py` re-grades the 27 T0 main and controls runs, which every T0 hypothesis test
   uses, and the 9 T0 compiler builds, with a numpy forward pass written line by line from `ARCHITECTURE.md` (the
   specification the agents get) and the metrics of preregistration §4. Only checkpoint loading uses project code.
   `scripts/audit7/clock_pizza_check.py` recomputes Zhong et al.'s distance irrelevance (Def. 4.2) for the 5 targets,
   the 9 compiler builds and the 27 agent runs with the same forward pass.
3. **Methods.** Code read against its sources and preregistration §4–§5: `grader/metrics.py`, `grader/score.py`,
   `grader/activations.py`, `analysis/stats.py`, `analysis/hypotheses.py`, `analysis/clock_pizza.py`,
   `simulator/audit.py`, and the sandbox files (`TASK.md`, `ARCHITECTURE.md`, the E0 and E1 texts).
4. **Build scripts.** Every reported run's final `build_weights.py` was scanned for loops that select among
   candidates, and each loop found was read in full (`scripts/audit7/build_script_searches.py`). The scripts are also
   public, one per run, at `replacements/<run_id>/build_weights.py` in
   [BurnyCoder/grading-explanations-by-simulation](https://huggingface.co/BurnyCoder/grading-explanations-by-simulation).
5. **Claims and citations.** Three parallel source checks read the cited papers in full: the modular-addition
   sources; automated interpretability, agents and product facts; and methods, statistics and infrastructure. Each
   discrepancy was then re-read by hand. Hugging Face repository dates were checked through the Hub API.

### 2.2 Scores

All 36 gradings reproduce the stored scores (27 T0 main and controls runs, 9 T0 compiler builds; largest differences 1.2e-11 in HS and 1.3e-11 in KL; `results/audit7/regrade.json`), so the inputs of H1–H4 and H5 on T0 are verified by code that shares only checkpoint loading with the project. Because the forward pass is written from `ARCHITECTURE.md`, the agreement also shows that the grader's model computes the network the agents were told they are building. H7, H8, the retrains and students, and the seed targets are not re-graded here.

Distance irrelevance reproduces for all 41 networks (largest difference 1.8e-11; `results/audit7/clock_pizza_check.json`):
every target is on the Clock side (q ≥ 0.4), and the agents' E1, E2 and E3 replacements average 0.18, 0.13 and 0.13
(Pizza side), E4 0.41, W-alg 0.001.

### 2.3 Methods against their sources

- **KL** is KL(P_M ‖ P_M̂) over the 113 number logits in float64, ACDC's direction (D_KL(G ‖ H), full model first).
- **HS** matches §4: ridge on training-fold-centred data with λ = 1e-6·tr(XᵀX)/d; pooled held-out R² with SST about
  the training-fold mean; clipped to [0, 1]; harmonic mean per site; mean over three sites. Regression R² is invariant
  only in its predictor (Kornblith et al. 2019, Table 1, where Y is the predictor of R²_LR); the repository states this.
- **Statistics.** H1's rule in code is JT p < 0.05 and ρ's CI above 0, as §5's falsifier states. Holm is step-down
  within H2 and within H4. The smallest-attainable-p rule uses 1/C(n₁+n₂, n₁) for Mann–Whitney and 1/2ⁿ for Wilcoxon.
- **Distance irrelevance** matches Zhong et al.'s Def. 4.2 term for term. Their §4.1.2 ranges (0–0.4 Pizza, 0.4–1
  Clock) and §4.1.3 ("the decisive factor") are quoted correctly; their Model A's gradient symmetricity is 99.37 %
  (the paper's 0.994 rounds it).
- **Sandbox.** `TASK.md`, `ARCHITECTURE.md` and the E0/E1 texts name no frequency and not the paper. E0 and E1 are
  byte-identical on all six targets (sha256), so pooling their runs across targets is valid.
- **Numbers checked by hand.** 226,816 weights; neurons per key frequency plus unclustered neurons sum to 512 on every
  target; T-paper's 44 neurons at k = 14 and 433 clustered neurons match Nanda et al. §4.3; chance share 5/56 = 9 %;
  the memorisation counts (5 of 6, 3 of 6, 68 %, 0.08 vs 0.70; E0 1 of 3, 36 %, 0.13 vs 0.28); H5's seed counts (6 of
  11 by sign, 4 beyond the CI); compiler gaps for W-scramble (T0 −0.093 at HS, resid_post 0.691 vs 0.951); the cost
  ($2.1998 summed over the 96 run records).
- **Dates.** The targets' Hugging Face repository was created 2026-10-21 01:08 UTC with first uploads at 02:23 and
  08:38 UTC (Hub API). Claude Haiku 5.5: training-data cutoff June 2026 and release 2026-10-07 (Anthropic model page).

## 5. What a reviewer should still weigh

- **N = 3, one task, one simulator.** H2 cannot pass at this N under either reading, so "HS separates true from wrong
  explanations" rests on H1's trend (driven by the E1 → E2 step), H3 (a comparison of means), H4 and H7, plus large
  descriptive gaps (E3 − W-freq +0.86, E3 − W-role +0.73).
- **What HS measures here.** It is close to a frequency-placement detector: a weights-only embedding-spectrum cosine
  orders most builds the same way, HS did not separate the agents' W-alg and W-scramble builds from the true ones, and
  the true explanations' own builds are Pizza-like by Zhong et al.'s diagnostic while T0 is a Clock. The paper says
  all of this; its claims are scoped to frequency-level content.
- **The agent repairs and searches.** Agents check accuracy in every run, announce searches in 44 of 96, and in 7 of
  96 the search sits in the final script. A score measures the explanation together with that repair; only the
  agent-free compiler measures the explanation alone.
- **Memorisation** on the published checkpoint is post hoc evidence from 6 + 3 runs of one simulator.

Nothing found in this audit invalidates the reported findings: the verdicts and the scores they use reproduce with
independent code, the metric implementation matches the preregistration, and the one protocol gap (F1) does not touch
any run that a hypothesis test uses.
